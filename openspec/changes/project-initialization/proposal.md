## Why

## What Changes

- 创建完整的 Vue 3 项目结构，包含 package.json 和所有必要的配置文件
- 安装核心依赖：Vue 3、Element Plus、Pinia、Vue Router、Vite
- 安装 PDF 导出相关依赖：html2canvas、jsPDF
- 创建项目目录结构，遵循 CLAUDE.md 中定义的规范
- 实现基础的三栏布局架构（左侧导航 + 中间编辑 + 右侧预览）
